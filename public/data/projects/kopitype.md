# Kopitype

## what is it?
kopitype is a singlish-themed typing test built by anselm. instead of typing boring english sentences, you type local words, MRT station names, and singlish quotes as fast as you can. it's deployed at kopitype.com.

## what are the features?
multiple corpora to type, real-time wpm and accuracy stats, pace charts, sound effects, a challenge mode, and a glossary of singaporean terms. it has a leaderboard too.

## what tech does it use?
built with next.js, typescript, and tailwind css. there's a separate leaderboard API running on a docker container on anselm's vps.

## why did you build it?
it was a fun way to combine his singaporean identity with a classic typing-test format. the singlish angle makes it stand out from generic typing sites.

## what is a typical feature you'd toot about?
the leaderboard and the challenge mode. you can race other people on typing singlish, which is a genuinely silly and fun thing.
