# Optifiner

## what is optifiner?
a self-evolving code framework anselm built at hack & roll 2026. you point it at a codebase and a benchmark, and it spawns 10+ parallel ai agents that each propose code changes. only the changes that measurably improve the benchmark survive into the next generation, and it runs multiple generations until it converges.

## what makes it work?
every improvement is benchmark-driven and tracked in git, so it's reversible. there's a live web dashboard to watch the evolution, and it works with claude, gpt-4, gemini and other models. it's at optifiner.dev.

## did it win anything?
yes, the team won a prize from marshall wace at hack & roll 2026: a stanley bottle.
