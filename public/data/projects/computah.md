# Computah

## what is computah?
computah is a desktop ai assistant built by anselm that can see the screen and operate the computer. it's at computah.anselmlong.com.

## what's interesting about it?
the security boundaries: explicit limits on what the assistant is allowed to touch, and a signed-app release workflow so people can trust the install.

## what tech does it use?
typescript and desktop automation, with local ai.
