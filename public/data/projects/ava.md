# Ava

## what is ava?
ava is anselm's personal agent. it runs on hermes agent on anselm's own vps, and he talks to it on telegram. it manages a lot of things for him.

## what can ava do?
ava has github and vercel integrations, and anselm uses it to build a lot of his projects straight from telegram.

## where does ava run?
self-hosted on anselm's vps, on hermes agent, with telegram as the interface.
